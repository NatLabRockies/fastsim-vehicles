# FASTSim Vehicle Database

This site searches the publicly available collection of vehicle models for NLR's
[FASTSim](https://github.com/NatLabRockies/fastsim) on-road vehicle powertrain simulation software. The database itself is located at [on GitHub](https://github.com/NatLabRockies/fastsim-vehicles).

See below to browse and download vehicle files directly.
See also the [About](about.md) page or relevant section of the
[FASTSim documentation](https://natlabrockies.github.io/fastsim/loading-vehicles)
for how to load vehicles from Python with `Vehicle.from_db`.
